# 📊 2024 스포츠 안전사고 실태조사 데이터 시각화 대시보드

> **Streamlit**을 활용하여 설문지의 복잡한 숫자 코드를 일반인들이 직관적으로 이해할 수 있는 종목명과 통계 차트로 자동 변환해 주는 스포츠 안전 데이터 분석 웹 대시보드입니다.

<br>

## 📌 1. 프로젝트 개요
* **개발 목적**: `2024 스포츠 안전사고 실태조사(체육인 대상)` 원천 데이터의 복잡한 구조(다중 선택 구조, 인덱스 코드)를 가공 및 정제하여, 사용자가 원하는 종목별 **부상 시간대**, **위험 장소**, **신체 부위별 부상 비율**을 원클릭으로 정밀 분석할 수 있도록 돕습니다.
* **주요 타겟**: 스포츠 안전에 관심이 있는 일반 사용자, 체육 시설 관계자, 보호 장구 및 스포츠 안전 정책 연구자

<br>

## 🛠️ 2. 기술 스택 및 환경
* **Language**: Python 3.10+
* **Framework**: Streamlit (Web Dashboard UI 구성)
* **Data Processing**: Pandas (헤더 병합, 데이터 마스킹 처리, 다중 응답 열 집계 연산)
* **Visualization**: Plotly Express (인터랙티브 파이 차트, 가로 바 차트)

<br>

## ✨ 3. 핵심 기능
대시보드는 사용자 편의성을 위해 **멀티 페이지 탭(Tabs) 구조**로 설계되었습니다.

### 🏠 탭 1: 기본 현황 분석
* **종목별 부상 신고 탑 10**: 전체 데이터 기준 가장 많은 안전사고가 접수된 상위 10개 종목을 차트로 시각화합니다.
* **부상 골든 타임 분석**: 다중 선택(체크박스형)으로 조사된 부상 시간대(새벽, 오전, 오후, 야간, 심야) 데이터를 동적으로 취합하여 도넛 차트로 제공합니다.
* **사고 위험 장소 분석**: 공공 시설, 민간 시설, 학교, 자연 환경 등 사고가 가장 빈번한 장소를 비교합니다.
* **텍스트 자동 요약 브리핑**: 선택한 스포츠 종목의 최다 부상 시간대와 고위험 장소를 AI 기반 스크립트 형태로 요약 안내합니다.

### 🤕 탭 2: 신체 부위별 부상 위험도 비교 (2페이지)
* **다중 컬럼 파싱**: 설문 데이터 내 23번째~60번째 열에 해당하는 신체 부위별 원시 코드를 자동으로 추적합니다.
